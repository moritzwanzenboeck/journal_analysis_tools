## One local web app for both notebook tools

- Open the launcher and choose **Create journal project** or **Clean and categorize papers** in your browser. The notebook controls load automatically and their code cells are hidden.
- Switch between the two pages in the same browser tab to keep unsaved edits. Save your work before closing or reloading the tab.
- Both pages fit the browser width. On narrow screens, the individual-paper summary stacks by category and keeps each copy button accessible.
- Continue using existing project folders, saved categorizations and exports. Standalone notebooks are still included. Use `--classic` on the Python launcher to open the original Jupyter controls.

Download the ZIP for Windows, Intel Mac, or Apple Silicon Mac under **Assets**. Each ZIP includes the compiled launcher and the bundled runtime. Extract the whole folder onto a local disk and open **Journal Notebook Launcher**.
