## Extract and open: Python and Jupyter included

The platform downloads now include Python, Tk, Jupyter and all notebook packages.
You no longer need to install Python, create an environment, run setup commands
or build the launcher.

1. Download the ZIP for your computer under **Assets**:
   - **Windows:** `Journal-Analysis-Tools-v1.3.0-windows-x86_64.zip`
   - **Intel Mac:** `Journal-Analysis-Tools-v1.3.0-macos-x86_64.zip`
   - **Apple Silicon Mac:** `Journal-Analysis-Tools-v1.3.0-macos-arm64.zip`
2. Extract the complete folder onto a local disk and keep its files together.
3. Open **Journal Notebook Launcher.exe** on Windows or
   **Journal Notebook Launcher.app** on Mac.
4. Start a service, then choose **Run All Cells** in its notebook.

GitHub's automatic **Source code** downloads contain neither the compiled app
nor the bundled runtime. Choose one of the platform ZIPs. Checksums accompany
each ZIP. Mac apps are ad-hoc signed rather than Apple-notarized; if blocked,
approve the app in **System Settings → Privacy & Security** if you trust it.

The launcher uses the runtime inside `app/python`; it downloads and installs
nothing when opened. You can move the complete tools folder without recreating
a Python environment. Projects and saved categorizations can stay on a shared
drive, while the tools remain local. Internet access is needed for Crossref
lookups, but text cleanup and saved-project work remain available offline.

All v1.2.0 workflows remain available: random journal sampling, manual DOI
selection with authors and cached metadata, text cleanup and full-paper
categorization. Existing projects and saved files are never overwritten.
To use the updated notebook inside an existing project, save active work as
JSON first and follow the notebook-update instructions in `dev/SETUP.md`.

Release checks require all six Windows/Intel Mac/Apple Silicon and Python
3.10/3.14 jobs to pass. Each platform package is extracted and moved, then tested
with system Python unavailable: native startup, Tk, both notebook services,
execution in bundled kernels, kernel termination and process cleanup.
