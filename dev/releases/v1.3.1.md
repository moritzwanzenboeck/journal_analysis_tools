## Mac download startup fix

Mac downloads contain Python, tools and templates inside the signed app. This
fixes startup when Gatekeeper runs a downloaded app from an isolated location.
All embedded Mach-O executables, libraries and extension modules are ad-hoc
signed before the outer app is sealed. Normal macOS approval may still be needed;
this release does not provide Apple notarization or remove quarantine attributes.

Editable notebooks live in the user account outside the app. Existing edits are
retained, and updated templates receive a separate workspace. New projects
default to Documents. Projects and saved categorizations remain in their chosen
folders. The Windows layout and workflows remain available.

The package check runs the actual Finder app, then exercises the embedded Python,
Tk GUI, both notebook services and kernels after ZIP extraction and relocation.
Signatures are checked again after startup. Source-level tests also cover an
app without adjacent tools and paths with spaces, quotes and Unicode.
