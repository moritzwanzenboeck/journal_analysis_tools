## Full-paper editing and project reports

- Edit section and subsection levels directly in cleaned text with Markdown headings. Labels and counts update as you edit. The reviewable outline lets you correct detected headings before saving.
- Add categories for an entire project. Removing a custom category moves its assignments to Unassigned in the current paper and in saved categorizations.
- Review article-level statistics and per-category summaries across a project. Reports use the latest saved categorization for each selected DOI, flag missing or invalid files, and include Copy controls for Excel.
- Long outlines and project report tables wrap and expand with the notebook page. The individual-paper summary keeps its copy buttons in place as values update.
- Random sampling and manual DOI validation exclude editorials, front and back matter, and similar non-scientific material. Project exports retain the source metadata and record selection decisions.

Choose the platform ZIP for Windows, Intel Mac, or Apple Silicon Mac. Each includes the compiled launcher and its Python runtime. See the included `README.md` for opening the app and using both notebooks.
