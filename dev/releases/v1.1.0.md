## Precompiled launchers for Windows and both Mac architectures

Download the ZIP matching your computer from **Assets** below, then extract the
complete folder onto a local disk:

- **Windows:** `Journal-Analysis-Tools-v1.1.0-windows-x86_64.zip`
- **Intel Mac:** `Journal-Analysis-Tools-v1.1.0-macos-x86_64.zip`
- **Apple Silicon Mac:** `Journal-Analysis-Tools-v1.1.0-macos-arm64.zip`

Each archive includes the compiled launcher, both notebooks, runtime support,
requirements, setup instructions and release metadata. No compiler or build step
is required. The automatic GitHub **Source code** downloads do not include the
compiled apps; choose a platform ZIP instead. SHA-256 files accompany each ZIP.

**One-time setup is still required:** install Python 3.10+ with Tk and install
`requirements.txt` into a fresh `.venv`, following `dev/SETUP.md`. Python/Jupyter
are not bundled. Keep the complete extracted folder together, then double-click
**Journal Notebook Launcher.exe** or **Journal Notebook Launcher.app**.

This version uses the notebooks for both project creation and text cleanup,
replacing the standalone interface in v1.0.0. The shared control window starts,
opens, stops and force-stops its two Jupyter services and kernels. Choose **Run
All Cells** after opening either notebook.

The packaged launchers are relocatable and contain no build-machine checkout or
Python fallback paths. On macOS, compilation happens on local temporary storage,
and the completed app is ad-hoc signed and validated before publication. Mac
apps are not Apple-notarized; use your organisation's normal approval process
for trusted downloaded software if macOS blocks the first opening.

Keep the tools and Python environment on a local disk. Analysis project output
can still be saved on a shared drive. Existing projects are never overwritten;
no `papers/` or `analysis/` folders are generated.

Release publication is gated on the compatibility suite on Windows, Intel macOS
and Apple Silicon macOS with Python 3.10 and 3.14, plus extraction/relocation and
native startup verification of each packaged download.
