## Manual paper selection and full-paper categorization

Create a project from a random journal sample or choose your own papers by DOI.
Clean copied PDF text and categorize whole papers by section in the notebooks.

### New in this release

- **Manual DOI selection:** search individual DOIs or check a pasted list, review
  titles, authors, journals and years, and create a project from the selected
  papers. Project creation reuses the metadata already retrieved during lookup.
- **Full-paper categorization:** review detected headings, assign sections and
  subsections, and copy category totals or the whole summary table into Excel.
  The original clean-and-count tab remains available.
- **Project-aware saving:** select papers from a generated project, reopen saved
  categorizations, and save cleaned text and assignment JSON in that project's
  `paper_categorizations` folder.
- **Clearer review controls:** assignment progress, unassigned-section highlights,
  a Not categorizable category, fixed summary controls and floating text previews.
- **More reliable DOI lookup:** rerunning the notebook refreshes an older loaded
  backend, and failed lookups release the controls so you can retry.

### Download and open

Choose the ZIP for your computer from **Assets**, then extract the complete
folder onto a local disk:

- **Windows:** `Journal-Analysis-Tools-v1.2.0-windows-x86_64.zip`
- **Intel Mac:** `Journal-Analysis-Tools-v1.2.0-macos-x86_64.zip`
- **Apple Silicon Mac:** `Journal-Analysis-Tools-v1.2.0-macos-arm64.zip`

Each ZIP includes its compiled launcher; no compiler or app-building command is
needed. GitHub's automatic **Source code** downloads do not include compiled apps.
SHA-256 checksum files accompany the platform ZIPs.

**One-time setup:** install Python 3.10+ with Tk and install `requirements.txt`
in a fresh local `.venv`, following `dev/SETUP.md`. Python and Jupyter are not
bundled. Keep the extracted folder together, open **Journal Notebook Launcher**,
start a tool and choose **Run All Cells** in its notebook. Mac apps are ad-hoc
signed, but are not Apple-notarized.

### Updating existing projects

Save active categorizations as JSON before restarting a kernel. Existing
projects contain their own notebook copy: copy the updated
`clean_and_count_text.ipynb` into the project to use the new controls there, or
open the central notebook and choose the existing project folder. Keep
`project.json`, `output/` and `paper_categorizations/` intact.

Publication requires the compatibility checks on Windows, Intel macOS and Apple
Silicon macOS with Python 3.10 and 3.14, plus extraction, relocation and native
startup verification of all three platform packages.
